# MILK

Every pool is a cow. Milk it.

A front end for adding liquidity to pump.fun PumpSwap pools in one click from SOL. Transactions are built with the official PumpSwap SDK and signed by the user's own wallet.

Env (optional): RPC_URL (private Solana RPC), MILK_JUG (wallet for the 0.1% add fee), MILK_CA, MILK_X, MILK_ALT.
